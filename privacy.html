Liqwy Factory

Privacy Policy

Effective date: November 6, 2026

Liqwy Factory is a private tool run by its owner on their own computer. It uses YouTube API Services to publish videos to YouTube channels the owner controls. By connecting a channel, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool uses

  • The connected channel's ID and title, to confirm that videos go to the right channel.
  • An OAuth refresh token, which lets the tool act on that channel.
  • The IDs of videos it has published, to avoid publishing the same video twice.

The tool does not read channel analytics, comments or subscriber information.

How the data is used

The data is used only to upload videos, set their details, captions, thumbnails and visibility, and add them to playlists on the connected channel.

Storage and sharing

The data is stored only on the owner's computer. It is not sold or shared with anyone, and the tool does not send it to any server other than Google's.

This website sets no cookies and has no forms or analytics. It is hosted on GitHub Pages, and GitHub may log visits as described in its own privacy statement.

Keeping and deleting data

The data stays on the owner's computer until the owner deletes it. You can remove the tool's access at any time in your Google Account permissions. To have stored data deleted, contact the address below.
